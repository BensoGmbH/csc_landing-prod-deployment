Connect your Bybit account

This guide explains how to securely connect your Bybit account to CryptoSignalCircle using a read-only API key.

CryptoSignalCircle cannot trade or withdraw funds from your account — it only reads your completed trades.

Demo vs. Production — which one should you use?​

Bybit offers both:

  • Demo account (paper trading)
  • Production account (real trading)

You can connect either to CryptoSignalCircle.
The steps for creating an API key are the same — only the starting point differs.

Step 1 — Open API settings​

If you are in Demo mode​

  1. Open the Trading interface
  2. Make sure you are in Demo mode
  3. Click your profile icon and select API Management

If you are in Production mode​

  1. Make sure you are in Production (Live) mode
  2. Open your profile menu
  3. Select API Management

Step 2 — Create a new API key​

  1. Click Create New Key
  2. Continue to the next step

Step 3 — Choose API key type​

Select:

  • System Generated API Key (recommended)

Then proceed.

Step 4 — Configure permissions​

Make sure your key is configured as Read Only.

CryptoSignalCircle does not need:

  • Trading permissions
  • Withdrawal permissions

⚠️ Do not enable withdrawals or trading.
CryptoSignalCircle only requires read access to your completed trades.

Step 5 — Security verification​

Complete the required verification (email, authenticator app, or both).

This is required before your API key is created.

Step 6 — Copy API Key & Secret​

Bybit will now display:

  • API Key
  • Secret Key

Copy both values and keep them ready.

⚠️ You may only see the Secret Key once — store it safely.

Step 7 — Add Bybit in CryptoSignalCircle​

  1. Open your CryptoSignalCircle dashboard
  2. Click Connect Exchange
  3. Select Bybit
  4. Add Account Nickname
  5. Paste:
    • API Key
    • Secret Key
  6. Select Account environment
  7. Click Save Connection

Step 8 — Start syncing your trades​

Once connected:

  • The initial sync may take a few minutes
  • Historical trades will load automatically
  • New trades will sync continuously

You can monitor sync status in your dashboard.

Disconnecting Bybit​

You can disconnect at any time by:

  • Removing Bybit in CryptoSignalCircle and
  • Deleting the API key directly in Bybit

⚠️ Important: When you disconnect an exchange account, all data associated with that account (including trade history and journal entries) will be permanently deleted from CryptoSignalCircle.
